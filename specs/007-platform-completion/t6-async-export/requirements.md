# T6 异步账本导出需求

## 目标

为开发者收益账本增加超过 5,000 行时的异步导出控制面，同时不在 Worker 或审计日志中拼装、保存或输出大规模账目正文；私有对象存储与真实下载签名器在 Wave B 基础设施批准前保持关闭。

## 必须行为

- 账本不超过 5,000 行时保留现有浏览器分页导出；超过 5,000 行时必须创建异步作业，不能继续在浏览器拉取全部正文。
- 作业只属于发起开发者；其他开发者不得读取、取消、重试或申请下载，管理员也不得借角色跨租户读取账本导出。
- 作业状态为 `queued | processing | completed | failed | cancelled | expired`，记录总行数、已处理行数、百分比、尝试次数和安全错误代码。
- 只有 `queued/processing` 可取消，只有 `failed` 可重试；重试递增 attempt 并清空旧进度，所有命令继续使用现有 `Idempotency-Key` 绑定。
- 内部导出处理接口必须由独立服务令牌保护；未配置令牌时 fail closed。领取、进度、完成和失败写入只追加安全事件，事件不得包含账目正文。
- 完成结果只保存私有对象引用、SHA-256、行数、字节数和内容类型；面向用户的作业响应不得泄露对象键。
- 完成制品保留 24 小时，排队/处理作业最长保留 7 天；到期后状态变为 `expired`，下载不可用，元数据和审计事件继续保留。
- 下载只能通过短期签名器签发；Wave A 未配置签名器时返回明确的 `EXPORT_STORAGE_NOT_CONFIGURED`，禁止回退到公开 URL。

## 可观察验收

- 收益中心在小账本时继续直接下载，在大账本时显示作业状态、进度、过期时间、取消和失败重试入口。
- D1 和 Memory Store 覆盖阈值、所有权、状态转换、并发领取/取消、失败重试、完成过期与安全制品视图。
- Worker API 覆盖幂等创建、跨用户 404、内部令牌门禁和未配置下载签名器的 fail-closed 行为。

## 明确排除

- 创建或修改对象存储、队列、外部导出 Worker、云服务绑定和生产 secrets。
- 在 Cloudflare Worker 内生成超过 5,000 行的 CSV，或把账目正文写入 D1 作业/事件表。
- 公开对象 URL、长期下载令牌、部署或生产数据迁移。
