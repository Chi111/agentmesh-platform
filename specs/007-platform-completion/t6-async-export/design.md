# T6 异步账本导出设计

## 控制面

`export_jobs` 保存所有者、资产过滤、状态、快照行数、请求时最后一条账目的 `(createdAt, id)` 上界、进度、attempt、租约、安全错误和 7 天作业期限。`export_artifacts` 只保存私有对象引用及校验元数据，制品期限固定为完成后 24 小时。`export_job_events` 是只追加审计流，detail 只允许状态、计数、attempt、worker 和错误代码，不接受账目行。

创建接口先在 Store 内按所有者与资产精确计数。`rowCount <= 5000` 返回 `direct`，前端继续使用既有游标下载；更大结果创建 `queued` 作业。HTTP 创建和重试使用现有幂等基础设施，数据库状态转换另有条件写保证。

## 处理服务接口

独立导出服务通过 `X-Export-Service-Token` 领取一个排队作业，获得所有者、资产过滤、行数与冻结游标快照，然后在外部私有环境按该上界分页读取并生成 CSV。服务仅回报计数进度，完成时提交私有 object key、摘要、行数和字节数。没有 `EXPORT_SERVICE_TOKEN` 时所有内部路由返回 503；T6 不创建该 secret 或外部服务。

## 下载与保留

用户作业视图隐藏 object key。下载令牌接口先验证所有权、`completed` 状态和制品期限，再调用注入的短期签名器；默认生产依赖为空并返回 `EXPORT_STORAGE_NOT_CONFIGURED`。Wave B 接入私有存储时可实现同一签名器接口，无需改变作业 API。

读取作业、领取和状态变更前都会推进到期状态。排队/处理作业创建后 7 天到期；完成后以制品 24 小时期为准。过期只关闭下载和处理，不删除历史元数据或审计。

## 安全边界

- 用户路由始终绑定认证用户 ID，没有管理员跨租户例外。
- 内部接口返回生成所需过滤条件，但不返回账本正文；Worker 不生成大文件。
- 审计事件字段由 Store 构造，调用方不能提交任意 detail。
- 下载签名器必须返回短期 HTTPS 地址且最大有效期 5 分钟；未配置时绝不暴露对象引用。
