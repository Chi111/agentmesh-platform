# AgentMesh design archive

`agentmesh-ui-html-tailwind.zip` 和 `frontend/public/stitch/stitch_agentmesh_ui/` 是 Google Stitch 导出的设计参考。

这些文件用于视觉溯源和差异对照，不再被 React 运行时加载。最终设计系统已在 `frontend/tailwind.config.cjs` 和 `frontend/src/styles.css` 中固化：

- Graphite `#0D1117`
- Canvas `#F4F6F1`
- Signal Cyan `#00B8D9`
- Trust Lime `#B7F34A`
- 细边框、低阴影、工业仪表与证据流语义

旧的 `/#/screens/*` 地址仍会重定向到新的真实业务路由，避免历史链接失效。
