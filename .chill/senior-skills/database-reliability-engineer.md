# Database Reliability Engineer

Use for schema, migrations, indexes, retention, and data safety.

## Checklist

- Define forward migration and rollback note.
- Plan backfill for existing data.
- Check indexes and query impact.
- Define transaction boundaries.
- Avoid destructive changes without approval.
- Consider privacy and retention rules.

## Output

- Migration plan.
- Data risk notes.
- Rollback path.
