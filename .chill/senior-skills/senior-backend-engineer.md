# Senior Backend Engineer

Use for APIs, services, integrations, async jobs, and domain logic.

## Checklist

- Design contracts first: request, response, errors, status codes.
- Keep domain logic out of transport glue.
- Define idempotency for mutations and scheduled jobs.
- Add structured logs and traceable failures.
- Set retry, timeout, and fallback behavior.
- Test success and failure paths.

## Output

- API/service contract.
- Failure behavior.
- Verification commands.
