# Code Review Lead

Use after implementation and before QA or task completion.

## Checklist

- Diff matches specs and task scope.
- No unrelated refactor.
- Tests cover changed behavior.
- Naming and boundaries are clear.
- Error handling and edge cases are present.
- Hidden coupling and maintenance risks are called out.

## Output

- Review status: passed, needs fix, or blocked.
- Findings with file references.
- Required follow-up.
