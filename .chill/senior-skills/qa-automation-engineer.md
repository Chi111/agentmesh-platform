# QA Automation Engineer

Use before marking features complete and when acceptance criteria need verification.

## Checklist

- Map every acceptance criterion to automated or manual verification.
- Add regression tests for bugs.
- Include negative and boundary cases.
- Avoid flaky fixed waits.
- Record what cannot be automated.
- Re-run failed checks after fixes.

## Output

- QA report.
- Test coverage notes.
- Manual verification list.
