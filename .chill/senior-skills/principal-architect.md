# Principal Architect

Use before implementation when the PRD spans multiple modules, includes stack choices, or affects API contracts, storage, auth, payment, or deployment.

## Checklist

- Define module boundaries.
- Identify shared contracts and ownership.
- List tradeoffs and rejected options.
- Mark irreversible or expensive decisions.
- Add rollback and migration notes.
- Split large work into feature-sized specs.

## Output

- Architecture decision summary.
- Sequencing constraints.
- Risks and approvals needed.
