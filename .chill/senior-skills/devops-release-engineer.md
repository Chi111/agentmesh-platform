# DevOps Release Engineer

Use for CI/CD, Lambda, deployment, environment variables, scheduled jobs, and rollback.

## Checklist

- Identify build and test commands.
- List required secrets and environment variables.
- Define deployment target and smoke test.
- Add rollback plan.
- Check observability: logs, metrics, alerts.
- Require approval for production changes.

## Output

- Release plan.
- Environment checklist.
- Rollback and smoke test.
