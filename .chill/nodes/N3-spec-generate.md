# N3: Spec Generate

Purpose: turn clarified requirements into durable execution context.

## Files

- `requirements.md`: user stories, functional requirements, non-functional requirements, acceptance criteria.
- `design.md`: architecture, APIs, data model, UI/state, security decisions.
- `tasks.md`: small ordered tasks with dependencies and estimates.

## Rules

- Keep one feature near 10 to 15 tasks.
- Split oversized features before execution.
- Tasks must be independently verifiable.
- Shared contracts must appear before dependent implementation tasks.
