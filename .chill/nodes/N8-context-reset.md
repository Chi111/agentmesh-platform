# N8: Context Reset

Purpose: avoid context drift between tasks.

## Steps

1. Confirm the task is marked complete in `tasks.md`.
2. Write useful lessons to `specs/LESSONS.md`.
3. Summarize current state.
4. Clear or compact active context.
5. Reload project profile, specs, rules, and lessons before the next task.

## Lesson Rule

Only record non-obvious decisions, pitfalls, environment facts, and cross-feature impacts.
